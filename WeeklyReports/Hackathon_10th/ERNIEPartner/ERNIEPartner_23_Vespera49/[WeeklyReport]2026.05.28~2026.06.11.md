     解决：通过星河社区申请并开通 ERNIE-4.5 系列模型权限，更新 Token 后恢复正常
   - 问题：手机 Termux 新建会话数达到上限，无法同时运行 Gateway 和 Agent

   - 问题：Agent 对话中偶发 Context overflow
     解决：使用 /new 命令创建新会话，或采用 /exec 斜杠命令执行系统任务
